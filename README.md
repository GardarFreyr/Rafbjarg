# Rafbjarg ehf. – hugmynd að forsíðu

Hönnunartillaga frá Garðar Vefur, án skuldbindingar. Þetta er **ekki** opinber vefur Rafbjargar ehf.

Staðfestar upplýsingar eru sóttar í [félagatal SART](https://www.sart.is/index.php/um-sart/felagatal) og [fyrirtækjaskrá Skattsins](https://www.skatturinn.is/fyrirtaekjaskra/leit/kennitala/4103220990). Sími og netfang eru virkir `tel:`/`mailto:` hlekkir. Það er ekkert eyðublað.

Opin atriði:
- Þjónustuflokkar: aðeins „Raflagnir“ er skráð starfsemi (ÍSAT 43.21). Hinir fjórir eru merktir sem sýnidæmi.
- Ljósmynd af Brynjari og kynningartexti (merkt sem staðgenglar).
- Myndir eru sýnimyndir af Wikimedia Commons (CC BY / CC BY-SA, höfundar taldir upp í fæti) og sýna ekki verk Rafbjargar.

Síðan er merkt `noindex` á meðan hún er tillaga.
